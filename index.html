Промпт для разработки проекта мессенджера Omnix

«Ты — ведущий ML/Fullstack/UX/UI разработчик и архитектор продукта. Разработай современный мессенджер под названием Omnix. Создай полный проект с описанием архитектуры, функционала, дизайна, технологии, структуры базы данных, планом разработки и тестирования.

Особое внимание удели: безопасности, сквозному шифрованию, P2P-архитектуре, удобному и красивому интерфейсу в стиле стеклянного (glassmorphism) дизайна, мобильной нижней навигации, поддержке всех платформ (веб, iOS, Android, Desktop).

Цель — создать быстрый, безопасный, функциональный и эстетичный мессенджер с уникальной концепцией Omnix: больше, чем просто общение. Это твоя вселенная.»

Ключевые требования

Название и концепция

Omnix — современный мессенджер с уникальной вселенной общения.

Функционал

Чаты, группы, каналы, голосовые и видеозвонки, медиа, файлы, статусы, боты, AI-помощник, настройки приватности.

Безопасность

Сквозное шифрование, P2P, защита данных, двухфакторная аутентификация.

Дизайн

Стеклянный интерфейс, минимализм, неоновые акценты, анимации, нижняя навигация (мобильная версия).

Платформы

Web, iOS, Android, Desktop.

Технологии

Flutter / React Native (мобильные), Next.js (web), Node.js (backend), PostgreSQL + Redis (база данных и кэш), WebRTC (звонки), Docker (развертывание).

Этапы разработки

Анализ → Проектирование → Дизайн → Разработка → Тестирование → Релиз → Поддержка.
